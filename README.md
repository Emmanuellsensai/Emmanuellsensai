# Hi, I'm Usang Emmanuel

### Founder & Software Engineer · Go, Python, TypeScript

I'm the Founder and Director of [KOLAPPTECH LTD](https://kolapp.tech), the company behind **Kola**, an AI voice agent that speaks English, Nigerian Pidgin and Yoruba. I build production backends and full-stack products from Lagos, Nigeria.

## What I'm building

- **[Kola](https://kolapp.tech)**: a multilingual voice agent that calls customers back for banks and businesses. FastAPI backend, Next.js dashboard, ElevenLabs and Twilio for the calls. Also available as [Kola for Business](https://business.kolapp.tech) for payment recovery and order follow-ups.
- **[Toolzng](https://toolzng.me)**: a live academic formatting platform for Nigerian students. Go backend, Python document service, running in production.
